# MiTechnoform para Android

Instalador oficial de MiTechnoform para Android. Este repositorio se utiliza exclusivamente para distribuir el APK; no contiene el código fuente de la aplicación.

## Descargar

[Descargar MiTechnoform.apk](https://github.com/alexfriu-ctrl/mitechnoform-android/releases/latest/download/MiTechnoform.apk)

Requiere Android 8.0 o posterior. Abre el APK descargado y, si Android lo solicita, permite la instalación desde el navegador utilizado.

Para acceder necesitas tu cuenta de MiTechnoform y completar la verificación de doble factor.

## Versión publicada

Primera publicación de distribución: v1.0.0. Versión interna de la aplicación: 1.0.7 (código 8).
